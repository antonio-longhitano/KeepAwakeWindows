# KeepAwake

KeepAwake is a lightweight Windows tray utility that prevents the PC and display from entering sleep mode.

It runs silently in the background and can be controlled from the Windows system tray. KeepAwake supports persistent settings, configurable timers, automatic startup and separate icons for active and inactive states.

No installation is required.

## Features

- Prevents Windows from putting the PC to sleep
- Prevents the display from turning off
- Runs silently in the system tray
- Enable or disable KeepAwake at any time
- Custom tray icons for active and inactive states
- Quick timers with configurable presets
- Automatic deactivation after a configurable amount of time
- Reset the currently running timer
- Displays the timer expiration time and remaining time
- Remembers the previous active/inactive state
- Optional automatic startup with Windows
- Single-instance execution
- Persistent configuration
- No external dependencies

## Requirements

- Windows
- Windows PowerShell
- .NET Framework / Windows Forms

The application uses the Windows `SetThreadExecutionState` API and does not require administrator privileges.

├── KeepAwake_On.ico
├── KeepAwake_Off.ico
├── KeepAwake.lnk

### `KeepAwake.ps1`

Main application.

It handles:

- sleep prevention
- system tray interface
- timers
- settings
- startup configuration
- icon management

### `KeepAwake.vbs`

Silent launcher used to start the PowerShell application without displaying a console window.

### `KeepAwake_On.ico`

Icon displayed when KeepAwake is active.

### `KeepAwake_Off.ico`

Icon displayed when KeepAwake is inactive.

### `KeepAwake.lnk`

Launcher automatically generated by KeepAwake.

It uses `KeepAwake_On.ico` as its icon and starts the application through `KeepAwake.vbs`.

### `KeepAwake.settings.json`

Automatically generated configuration file containing the user's settings.

## Installation

Clone or download the repository:

```powershell
git clone https://github.com/<username>/KeepAwake.git
```

Alternatively, download the repository as a ZIP and extract it.

Keep the following files in the same directory:

```text
KeepAwake.ps1
KeepAwake.vbs
KeepAwake_On.ico
KeepAwake_Off.ico
```

Run:

```text
KeepAwake.vbs
```

On the first launch, KeepAwake automatically creates:

```text
KeepAwake.lnk
KeepAwake.settings.json
```

After that, `KeepAwake.lnk` can be used as the normal application launcher.

## Usage

Once started, KeepAwake runs in the Windows system tray.

Right-click the tray icon to access the main controls.

The tray icon indicates the current state:

- `KeepAwake_On.ico` — KeepAwake is active
- `KeepAwake_Off.ico` — KeepAwake is inactive

Double-click the tray icon to open the settings window.

## Quick Timer

The **Timer rapido** menu allows KeepAwake to be enabled for a predefined amount of time.

The default presets are:

```text
30 minutes
1 hour
2 hours
4 hours
```

The four presets can be changed from the settings window.

Selecting **Senza limite** enables KeepAwake without an expiration time.

When a timer is running, the tray status displays both the expiration time and the remaining duration.

The **Riavvia timer** command restarts the currently active timer using its original duration.

## Settings

The settings window provides the following options:

### KeepAwake active

Enables or disables sleep prevention.

### Automatic deactivation

Automatically disables KeepAwake after the configured number of minutes.

### Start with Windows

Automatically launches KeepAwake when the user logs into Windows.

The previous active/inactive state is preserved between executions.

### Quick Timer presets

Configures the four durations displayed in the **Timer rapido** menu.

## Apply and close behavior

Changes made in the settings window are not applied immediately.

Click:

```text
Applica
```

to save and apply the current settings.

The settings window remains open after applying the changes.

Clicking the window's **X** button only hides the window. KeepAwake continues running in the system tray.

Click:

```text
Esci
```

to completely terminate KeepAwake.

The application can also be terminated using **Esci** from the tray menu.

## Start with Windows

When **Avvia con Windows** is enabled, KeepAwake creates a shortcut in the current user's Windows Startup folder.

No registry modifications are required.

Disabling the option removes the startup shortcut.

## How it works

KeepAwake calls the Windows API:

```text
SetThreadExecutionState
```

While KeepAwake is active, it periodically requests that Windows keep both the system and display awake.

Conceptually, it uses:

```text
ES_CONTINUOUS
ES_SYSTEM_REQUIRED
ES_DISPLAY_REQUIRED
```

When KeepAwake is disabled or the application exits, the execution state is restored.

KeepAwake does not simulate keyboard presses or mouse movement.

## Configuration

Settings are stored locally in:

```text
KeepAwake.settings.json
```

Example:

```json
{
    "Enabled": true,
    "AutoDisable": false,
    "AutoDisableMinutes": 60,
    "StartWithWindows": false,
    "QuickTimerPresets": [
        30,
        60,
        120,
        240
    ]
}
```

The configuration file is created automatically and does not need to be edited manually.

## Running only one instance

KeepAwake uses a named Windows mutex to prevent multiple instances from running simultaneously.

Starting KeepAwake while another instance is already running will not create a second background process.

## Project structure

KeepAwake intentionally uses standard Windows components:

- PowerShell
- Windows Forms
- Windows Script Host
- Windows API
- Windows shortcuts

This keeps the project small and avoids additional runtimes, installers or third-party dependencies.
